# PDF文書比較ツール セットアップガイド

2つのPDFをアップロードすると、Claude APIが差分・一致点・固有内容を分析して表示するWebアプリです。

---

## 動作環境

- Windows 10 / 11
- Node.js 18 以上
- Anthropic API キー（Claude 利用可能なもの）

Node.js のバージョンはコマンドプロンプト（または PowerShell）で確認できます。

```
node -v
```

Node.js が入っていない場合は https://nodejs.org/ からインストーラーをダウンロードしてください（LTS版を推奨）。

---

## セットアップ手順

### 1. 依存パッケージのインストール

プロジェクトルートで実行します。

```bash
npm install
```

### 2. 環境変数ファイルの作成

プロジェクトルートに `.env` ファイルを作成し、APIキーを記載します。

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxx
```

`.env` はGit管理対象外になっています（`.gitignore` に記載済み）。APIキーを誤ってコミットしないよう注意してください。

### 3. アップロード用ディレクトリの確認

サーバー起動時に自動生成されますが、存在しない場合は手動で作成してください。

```
mkdir uploads
```

### 4. サーバー起動

```
npm start
```

起動後、ターミナルに以下が表示されます。

```
PDF比較アプリが起動しました: http://localhost:3001
```

ブラウザで `http://localhost:3001` にアクセスすると、アプリが使えます。

---

## 開発時の起動方法

ファイル変更を検知して自動再起動します。

```
npm run dev
```

---

## 使い方

1. ブラウザで `http://localhost:3001` を開く
2. 「文書1」と「文書2」にPDFをそれぞれアップロード（各10MB以内）
3. 「比較を実行する」ボタンを押す
4. AIが分析を完了すると、一致点・相違点・固有内容が表示される
5. 必要に応じて「レポート形式」または「メール形式」に変換できる

---

## ポート番号の変更

デフォルトは `3001` です。変更する場合は `.env` に追記します。

```
PORT=8080
```

---

## トラブルシューティング

### APIキーエラーが出る場合

`.env` ファイルがプロジェクトルートに存在するか確認します。ファイルパスの誤りや、キーの前後に余分なスペースが入っていないか確認してください。

### PDFが受け付けられない場合

対応しているのはPDFファイルのみです（`.pdf` 拡張子、MIMEタイプ `application/pdf`）。1ファイルあたり10MBを超えるものはアップロードできません。

### `npm install` でエラーが出る場合

Node.js のバージョンが18未満の場合に発生することがあります。`node -v` でバージョンを確認してください。

### コマンドプロンプトで `node` が見つからないと言われる場合

Node.js インストール後に一度コマンドプロンプトを閉じて再度開くと解決することがあります。それでも動かない場合は、インストール時に「Add to PATH」にチェックが入っていたか確認してください。
