--------------------------------------------------------------------
  セッション別の使い方
--------------------------------------------------------------------

[Session 1] AI駆動開発とは（座学）
  配布ファイルの使用なし。


[Session 2] 環境構築ハンズオン
  配布ファイルの使用なし。
  研修教材の手順に沿って、Node.js と Claude Code をインストールします。
  デスクトップに training フォルダを作成するところから始めます。


[Session 3] ミニ業務アプリ開発
  Claude Code がコードを生成するため、事前のファイル準備は不要です。
  研修教材に記載のプロンプトをコピーして使います。

  うまくいかなかったときは:
    Session3_チェックリストアプリ/参照用_完成版/checklist.html
    をブラウザで開いて、完成形を確認できます。


[Session 4] PDF文書比較ツールを作る ★ 配布ファイルを使用します

  (1) 作業フォルダの準備
      training フォルダの中に my-pdf-compare フォルダを作成してください。

  (2) サンプルPDFのコピー
      Session4_PDF比較ツール/sample-data/ の中身をすべて
      my-pdf-compare/sample-data/ にコピーしてください。

  (3) APIキーの設定
      共通/.env.example を my-pdf-compare/ にコピーし、
      ファイル名を .env に変更してください。
      ファイルを開いて、講師から配布されたAPIキーを記入します。

  (4) 開発
      研修教材の手順に沿って、自分のプロンプトで開発を進めます。

  行き詰まったときは:
      Session4_PDF比較ツール/参照用_完成版アプリ/ の中身を参照できます。
      この完成版を動かす場合は、フォルダ内の SETUP.md をお読みください。


[Session 5] 生成AI資格ガイド（座学）
  配布ファイルの使用なし。


[Session 6] 自由開発 & 成果発表

  API を使うアプリを開発する場合は、
  共通/.env.example を作業フォルダにコピーし、
  ファイル名を .env に変更して APIキーを記入してください。


[Session 7] アプリを届けるには（座学）
  配布ファイルの使用なし。


--------------------------------------------------------------------
  注意事項
--------------------------------------------------------------------

- .env ファイルには APIキーが含まれます。
  スクリーンショットや画面共有で映り込まないよう注意してください。

- sample-data のPDFはダミー文書です。
  個人情報や社外秘情報は含まれていません。

- 完成版アプリはあくまで参照用です。
  まずは自分のプロンプトで開発に挑戦してみてください。
